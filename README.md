# Varify

Varify is a developer-first VS Code extension for managing environment variables.

## Features

- **Validate Env Files** – compares `.env` with `.env.example` and reports missing or extra keys.

## Usage

1. Open a workspace that contains both `.env` and `.env.example` files.
2. Run the command **Varify: Validate Env Files** from the Command Palette.
3. The extension will notify you about missing or extra keys.
